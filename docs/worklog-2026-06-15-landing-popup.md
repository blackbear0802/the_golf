## DB 설정 변경 (코드 외, Neon AppConfig)

- `bodyBlocklist`: `위더스` 포함 확인(이미 존재). 코드 기본값 `위더스골프` → `위더스`로 동기화.
- `landingProductId`: 천진 진황도 상품으로 변경한 이력 있음(이후 어드민이 재변경).

## 핵심 파일

- `src/components/LandingHeroDealClient.tsx` — 오늘의 초특가 배너 + 팝업(모달). 공유 버튼, 올포함 배지(`✓ 올포함`, 브랜드 채움), 3박4일 표기, 히어로 이미지, 갤러리.
- `src/components/LandingHeroDeal.tsx` — 서버 컴포넌트. 상품/미디어/operators 로드 후 가공해 전달.
- `src/components/FloatingDeals.tsx` — 이번주 특가(모바일 하단 고정 바 / 데스크톱 우측 사이드바).
- `src/lib/product-detail.ts` — 상세 표시용 가공 공용 헬퍼.
- `src/lib/featured-config.ts` — 특가/랜딩 지정 id 조회(삭제 보호용).
- `src/app/page.tsx` — 홈. `main`을 flex 컬럼으로 두고 `order`로 오늘의 초특가 위치를 뷰포트별 분리.
