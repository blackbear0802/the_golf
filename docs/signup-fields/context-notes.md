# 회원가입 추가 항목 — 컨텍스트 노트

## 배경
기존 회원가입은 이름/이메일/휴대전화/비밀번호만 수집. 마케팅·상품추천용 데이터와
법적 약관 동의 기록을 위해 항목을 확장한다.

## 결정과 근거
- **약관만 필수, 나머지 선택**: 가입 이탈률을 낮추기 위해 개인정보성 항목은 선택으로.
  (사용자 선택: "약관만 필수, 나머지 선택")
- **약관 3분할 + 전체동의**: 이용약관·개인정보는 필수 2개, 마케팅은 선택 1개로 분리해
  마케팅 동의를 법적으로 분리 기록. `termsAgreedAt`/`privacyAgreedAt`/`marketingAgreedAt`
  타임스탬프로 저장(동의 시점 근거 보존).
- **구력·핸디캡·지역은 String 카테고리**: 자유입력 숫자 대신 셀렉트 카테고리로 저장해
  집계·필터가 쉽고 입력 부담이 적다. enum 대신 String으로 두어 옵션 조정이 유연.
- **성별은 Gender enum(male/female)**: 정형 값이라 enum. 선택 항목이라 nullable.
- **마이그레이션은 `prisma db push`**: 이 프로젝트는 migrations 폴더 없이 db push 사용.
  생성 클라이언트 경로 `src/generated/prisma`.

## 옵션 정의 (signup-options.ts)
- 성별: 남성/여성 → male/female
- 구력: 1년 미만 / 1~3년 / 3~5년 / 5~10년 / 10년 이상
- 핸디캡: 100타 이상 / 90타대 / 80타대 / 싱글(70타대) / 잘 모름
- 거주지역: 서울·부산 등 17개 시·도

## 서버 검증
- 약관: agreeTerms && agreePrivacy true 아니면 400.
- 선택 셀렉트값(gender/career/handicap/region): 제공 시 허용 목록 멤버십 검증.
- 생년월일: 제공 시 유효 날짜 + 미래 아님 + 합리적 연령 범위.
