# 상품 상세 페이지 재구성 계획

## 요구
구조화 항목(날짜·가격·박수·인원·마감)은 그대로 분리 표시하되, **원본 본문을 그대로**(연락처만 제거) 보여주고, 이미지는 카테고리 썸네일 그리드 대신 **업로드 순서대로 풀폭 세로**로. 순서: 구조화 항목 → 본문 → 이미지.

## 결정 (사용자)
- 본문: `stripContacts(rawText)` — 공급자 전화·카톡·이메일만 제거, 나머지 원문 그대로. (공개 페이지 연락처 노출 = 플랫폼 우회 방지)
- 포함/불포함 불릿 섹션: **유지** + 본문 추가(중복 감수).
- 이미지: `type!=youtube` 미디어를 `order` 오름차순으로 풀폭 세로 나열, 캡션 있으면 하단.
- 히어로 이미지: **제거**(요청 레이아웃에 없음 + 스택과 중복). → golf/accommodation/dining/heroImage 변수·MediaGallery 컴포넌트 제거(고아).

## 최종 페이지 순서
헤더(목적지/골프장) → InfoCell(출발/기간/인원/가격)+마감 → **본문(연락처 제거 원문)** → **이미지(순서대로 풀폭)** → 유튜브 영상 → 포함/불포함 → 예약 CTA → 하단 고정바

## 영향
- `src/app/products/[id]/page.tsx`만: import stripContacts, 이미지 변수 정리, 히어로 제거, 본문/이미지 섹션 추가, MediaGallery 제거.
- 쿼리 무변경(미디어 include 그대로, 정렬은 JS에서 order). 다른 페이지·DB·API 무영향.

## 비목표
- 본문 마크다운/리치 렌더(그대로 텍스트 + whitespace 보존만). 이미지 라이트박스/캐러셀. 미디어 타입 그룹 표기.

## 리스크
- rawText 비어있는 기존 상품(수동 ProductForm 생성 등) → 본문 섹션 미표시(폴백 OK).
- stripContacts가 본문 일부 오제거 가능(기존 included/excluded와 동일 함수라 일관, 허용).
